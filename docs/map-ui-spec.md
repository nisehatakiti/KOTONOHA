# KOTONOHA 地図UI・距離ルール確定仕様

最終更新: 2026-09-08

この文書は、KOTONOHAの地図画面における「言の葉」の表示、距離による閲覧制御、ピンタップ時のUI、および接続投稿の扱いに関する確定仕様である。実装・修正時は、本書を地図UI仕様の正本（Single Source of Truth）として扱う。

## 1. 基本概念

### Root投稿
- 写真付きで投稿される最初の「言の葉」
- 地図上ではRoot投稿のみが葉っぱピンとして表示される
- 接続投稿の親になる
- 地図上の場所を表す投稿

### 接続投稿
- Root投稿に「言葉を繋ぐ」投稿
- 写真は持たない
- parent_idによってRoot投稿に紐づく
- 地図上に独立したピンは表示しない
- Root投稿の言葉に続く言葉として扱う

地図上の1枚の葉っぱピンは、「その場所に置かれたRoot投稿と、それに繋がれた言葉の束」を表す。

## 2. 距離ルール

KOTONOHAの距離ルールは次の3段階である。

| 距離 | 許可されること |
|---|---|
| 現在地から3km以内 | Root投稿の葉っぱピンが地図上に表示される |
| Root投稿から5m以内 | Root投稿の詳細な内容および接続投稿を閲覧できる |
| Root投稿から5m以内 | Root投稿に新しい言葉を繋ぐことができる |

- 3km = その言の葉の存在が地図上に見える距離
- 5m = その場所に近づいて中身をひらける距離

3kmルールと5mルールは別の概念として扱う。

## 3. 地図上のピン表示

### 3.1 表示対象
現在地から3km以内のRoot投稿のみ表示する。接続投稿は現在地との距離に関係なく地図上に独立したMarkerを表示しない。

### 3.2 3km判定
表示条件は、現在地からRoot投稿までの距離が3000m以下であること。

実装上は、
1. 現在地を中心とした3kmのBounding Boxで候補を取得
2. Haversine公式で実距離を計算
3. 3km以内の投稿のみMarker化

という二段階方式を使用する。

### 3.3 現在地が取得できない場合
現在地未確定時は3km判定ができないため、無制限に投稿を取得・表示してはならない。Root投稿の取得およびMarker表示を行わない。

## 4. 現在地の扱い

現在地は地図上で重要な視覚要素として扱わない。

- 常時現在地を示す大きなピンは表示しない
- 現在地Markerを主張の強いデザインにしない
- 現在地を追跡する機能は実装しない
- バックグラウンド位置監視は行わない

「地図を更新」等で現在地を取得した際には、
- 現在地を取得
- 地図を現在地付近へフォーカス
- 現在地から3km以内のRoot投稿を再取得・表示

する。

## 5. 葉っぱピンのデザイン

Root投稿を表すMarkerは、誰が見てもできるだけ「葉っぱ」に見えるデザインを目指す。

一般的な地図Markerや単なる丸いピンではなく、
- 葉の輪郭
- 葉の先端
- 葉の付け根
- 茎または硬い部分

が視覚的に理解できる形とする。

葉の付け根・茎にあたる部分が地面側の投稿位置を指す。つまり「葉っぱそのものが地面に刺さっている」ようなイメージを基本とする。

## 6. ピンタップ時のUI

Root投稿の葉っぱピンをタップすると、地図画面を維持したまま、その場所に「葉っぱが開く」ような吹き出し型UIを表示する。

通常のBottom Sheetや一般的なInfoWindowではない。

### 6.1 開いた状態
吹き出し表示中は、元の小さい葉っぱピンを非表示にする。

これにより「地図上の葉っぱがそのまま大きく開いた」ように見せる。小さいピンと大きい吹き出し葉っぱを同時に表示してはならない。

### 6.2 吹き出しの形
吹き出しは通常の四角いウィンドウではなく、地図上の葉っぱピンをそのまま拡大・展開したような形を基本とする。

- 葉っぱのシルエットを維持する
- 葉の向きは通常のMarkerと同じ、またはより垂直寄り
- 葉の付け根・硬い部分が下方向に伸びる
- その部分がRoot投稿の位置を指す
- 吹き出しの下端が地面側の投稿地点と自然につながる

「小さな葉っぱが開いて、その葉自体が投稿内容を見せている」という表現を目指す。

## 7. ピンタップ時の5mルール

ピンタップ時は、Root投稿と現在地の距離によって表示内容を切り替える。

### 7.1 Rootから5m超
表示可能：
- Root投稿のコメント
- Root投稿の投稿日時

表示しない：
- Root投稿の写真
- 接続投稿
- 接続投稿に関する情報
- 「言の葉をひらく」ボタン
- 「繋ぐ」機能

遠くからは「そこにどんな言葉が置かれているか」は見えるが、中身をひらくことはできない。

### 7.2 Rootから5m以内
表示可能：
- Root投稿のコメント
- Root投稿の投稿日時
- Root投稿に繋がれた接続投稿の言葉
- 「言の葉をひらく」ボタン

地図上では写真を表示しない。Root投稿の写真は5m以内であっても地図上の吹き出しには表示しない。写真は詳細画面で表示する。

## 8. 「言の葉をひらく」

5m以内の場合のみ、吹き出し内に「言の葉をひらく」ボタンを表示する。

「詳細を見る」は使用しない。

このボタンを押すとRoot投稿の詳細画面へ遷移する。

## 9. 詳細画面

詳細画面ではRoot投稿の内容をより詳しく表示する。

表示対象：
- Root投稿の写真
- Root投稿のコメント
- Root投稿の投稿日時
- Root投稿に繋がれた言葉

詳細画面には「繋ぐ」操作への導線を置く。写真は地図上の吹き出しではなく、この詳細画面で初めて大きく表示する。

## 10. 「繋ぐ」

「繋ぐ」はRoot投稿から新しい言葉を接続投稿として投稿する操作である。

接続投稿は、
- 写真なし
- コメントのみ
- parent_id = 対象Root投稿のid

として保存する。

接続投稿は新しい地図Markerを作らない。投稿成功後も地図上には親であるRoot投稿の葉っぱピンだけが存在する。接続された言葉は、そのRoot投稿の中に連なる言葉として扱う。

## 11. 距離判定中のUI

「距離を計測中です」「距離を確認しています」などのテキストメッセージは表示しない。

距離や詳細情報の取得中であることを示す必要がある場合は、葉っぱをモチーフにした軽いアニメーションを使用する。

例：
- 葉っぱがゆっくり回る
- 葉っぱが軽く揺れる
- 葉っぱがひらくように動く

派手なローディング演出にはせず、KOTONOHAの世界観を壊さない静かで自然なアニメーションを優先する。

## 13. データの表示原則

### 地図
表示する：
- 3km以内のRoot投稿の葉っぱピン
- ピンタップ後のRoot投稿吹き出し
- 5m以内の場合のみ接続投稿の言葉

表示しない：
- Root投稿の写真
- 接続投稿の独立Marker
- 現在地の主張の強いMarker

### 詳細画面
表示する：
- Root投稿の写真
- Root投稿の言葉
- 接続投稿の言葉
- 「繋ぐ」導線

## 14. 実装上の注意

- Root投稿と接続投稿の親子関係は空間距離ではなくparent_idを唯一の判定基準とする
- 接続投稿を近くにある別Root投稿と混同してはならない
- 3km判定はMarker表示のための判定
- 5m判定は閲覧・詳細・接続のための判定
- 3km以内であることと5m以内であることは別条件
- 位置情報取得に失敗した場合は、安全側として詳細情報・接続投稿・詳細画面導線を表示しない
- 地図上では写真を表示しない
- 選択中のRoot投稿の小さいMarkerは、展開中の吹き出しと同時表示しない
- 吹き出しを閉じると通常の葉っぱピンを再表示する

## 15. UI修正時の優先順位

地図UIを変更する場合は、以下を優先する。

1. 「言の葉」という世界観
2. 葉っぱが投稿場所に生えている感覚
3. ピンタップ時に葉っぱがそのまま開く感覚
4. 地図を写真一覧にしないこと
5. 現在地を主張しすぎないこと
6. 距離ルールをUI上で説明しすぎず、自然な体験として成立させること

この方針を変更する場合は、本書を更新してから実装を変更する。
