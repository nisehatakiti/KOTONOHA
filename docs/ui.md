# 言の葉を置く — v0.1 UI / Screen Specification

## 1. 基本画面

v0.1の基本画面は、1画面を中心としたシンプルな構成とする。

```text
┌─────────────────────────┐
│       広告バナー         │
├─────────────────────────┤
│                         │
│          地図            │
│                         │
│     ●       ●           │
│              ●          │
│          現在地          │
│                         │
├─────────────────────────┤
│  [ 地図を更新 ] [ 言の葉を置く ] │
└─────────────────────────┘
```

### 地図

- 画面中央の主要領域を地図表示とする。
- 現在地を表示する。
- 現在地から半径5km以内に存在する言の葉をピンとして表示する。
- 地図はユーザーが通常の地図操作として拡大・縮小、移動できるものとする。
- 言の葉のピンは地図上に表示するが、10m以内に入るまでは内容を表示しない。

### 広告

- 地図のさらに上部に広告バナー領域を配置する。
- 広告は主要操作を妨げない。

### 下部ボタン

地図の下に以下の2つの主要操作を配置する。

1. **地図を更新**
2. **言の葉を置く**

## 2. 地図の更新

地図情報・周辺の言の葉・現在地はリアルタイムでは更新しない。

ユーザーが「地図を更新」を押したときに、以下を実行する。

1. 端末から現在地を取得する。
2. 現在地を地図上に反映する。
3. 現在地を基準として周辺の言の葉をサーバーから取得する。
4. 地図上の言の葉ピンを更新する。

位置情報の常時追跡・常時送信は行わない。

## 3. 言の葉を置く

「言の葉を置く」を押した場合、投稿処理を開始する前に**必ず最新の現在地を取得し、地図を更新する**。

これにより、言の葉を置く直前に表示される現在地が最新の位置情報であることを保証する。

その後、投稿可能条件を満たしている場合のみアプリ内カメラを起動する。

### 投稿フロー

```text
[言の葉を置く]
       ↓
[現在地を取得]
       ↓
[地図を更新]
       ↓
[投稿可能条件を確認]
       ↓
[カメラ起動]
       ↓
[写真撮影]
       ↓
[写真確認]
       ↓
[50文字以内の言葉を入力]
       ↓
[保存]
       ↓
[サーバーへ送信]
       ↓
[言の葉を置く]
```

### 写真

- 写真は必ずアプリ内カメラを起動して、その場で撮影する。
- **端末に保存済みの写真・写真ライブラリ・ファイルから画像を選択する機能は実装しない。**
- 撮影した写真を確認してからコメント入力・保存へ進む。
- サーバーへアップロードされた画像は、そのまま元解像度で保存せず、サーバー側で表示用に縮小・圧縮して保存する。
- 原則として元画像は保存しない。
- 縮小後の画像サイズ・圧縮率は、実機での表示品質とストレージ使用量を確認して決定する。

## 4. ピン選択

地図上の言の葉ピンを選択すると、その地点に存在する複数の言の葉を選択できるUIを表示する。

複数存在する場合は、写真を中心としたタイル状の一覧とする。

各タイルから対象の言の葉を選択する。

## 5. 言の葉詳細

タイルから言の葉を選択し、10m以内にいる場合、その言の葉の詳細画面を表示する。

詳細画面は**写真を画面いっぱいに表示することを基本**とする。

```text
┌─────────────────────────┐
│                         │
│                         │
│         写真            │
│                         │
│                         │
│                         │
├─────────────────────────┤
│  今日はここから見る      │
│  空がきれいだ。          │
│                         │
│ [言葉を繋ぐ]  [通報する] │
└─────────────────────────┘
```

表示する基本情報:

- 写真
- 置かれた言葉
- 日時

写真は言の葉の主役として大きく表示し、言葉は写真の下部に配置する。

### 言葉を繋ぐボタン

5m以内の場合のみ「言葉を繋ぐ」を選択できる。

「言葉を繋ぐ」を選択すると、詳細画面上に50文字以内のテキスト入力欄を表示する。

```text
┌─────────────────────────┐
│         写真            │
├─────────────────────────┤
│ 元の言葉                │
│                         │
│ [ここに言葉を入力      ] │
│                         │
│             [保存]       │
└─────────────────────────┘
```

入力後に「保存」を押すと、対象の言の葉に新しい言葉を追加する。

写真撮影は行わない。

保存成功後は、追加された言葉を表示する。

### 通報するボタン

言の葉詳細画面には「通報する」ボタンを配置する。

「通報する」を選択すると、通報理由を選択してサーバーへ送信する。

通報が正常に受理されたら、**言の葉詳細画面（パネル）を閉じて基本画面へ戻る**。

## 6. 言葉を繋ぐ

「言葉を繋ぐ」は文字入力のみとする。

- 写真撮影は行わない。
- 既存写真の選択も行わない。
- 50文字以内。
- 対象の言の葉を明示した上で入力する。
- 「保存」押下でサーバーへ送信する。
- 送信成功後、対象の言の葉のスレッドに追加する。

## 7. 通報

言の葉詳細画面から対象の言の葉を通報できる。

「通報する」を選択すると理由を選択して送信する。

通報成功後は詳細画面を閉じ、基本画面へ戻る。

## 8. UIの基本方針

- 機能を詰め込みすぎない。
- 地図と「言の葉」に集中できる画面構成とする。
- ユーザー名やプロフィール等のSNS的UIは表示しない。
- 距離によって「見える」「触れられる」「繋げられる」という体験の差を明確にする。
- 言の葉詳細では写真を主役として扱う。
