# KOTONOHA

## 言の葉を置く

その場所で見た風景と言葉を、そこに置いていくスマートフォンアプリ。

遠くから見つけて、近づいて触れて、同じ場所から言葉を繋ぐ。

## 距離ルール（確定仕様）

KOTONOHAでは、現在地からの距離によって「発見できる」「触れられる」「繋げられる」範囲を分ける。

### 1. 3km以内：葉っぱピンが表示される

- ユーザーの現在地から半径3km以内にあるRoot投稿のみ、地図上に葉っぱピンとして表示する。
- 接続投稿（parent_idを持つ投稿）は地図上にピン表示しない。
- 3kmを超えるRoot投稿は、地図をズームアウトしても取得・表示しない。

### 2. ピンタップ時：5m超

Root投稿から5mを超える場合、吹き出しには以下のみ表示する。

- Rootのコメント
- 投稿日時

以下は表示しない。

- Root写真
- 接続投稿
- 詳細ボタン
- 繋ぐ機能

### 3. Root投稿から5m以内

Root投稿から5m以内の場合、吹き出しでは以下を表示できる。

- Rootのコメント
- 投稿日時
- Root写真
- 接続投稿一覧
- 詳細ボタン

詳細画面ではRoot投稿の内容を閲覧でき、［繋ぐ］からコメントのみの接続投稿を行える。

### 4. 接続投稿

- 接続投稿は親Root投稿にparent_idで紐づく。
- 接続投稿には写真を付けない。
- 接続投稿は新しい地図ピンを生成しない。
- 接続された言葉は、親Root投稿の言葉に連なる形で表示する。

## 距離設計の考え方

- **3km**：言の葉の存在を発見できる距離
- **5m**：言の葉の中身に触れ、写真や繋がった言葉を閲覧し、新しい言葉を繋げられる距離
