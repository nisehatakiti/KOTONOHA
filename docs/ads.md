# KOTONOHA — 広告仕様 v0.1

## 1. 配置

メイン画面の地図より上部に広告バナー領域を配置する。

画面構成は以下を基本とする。

1. 広告バナー
2. 地図（言の葉のピンを表示）
3. 地図更新・言の葉を置くボタン

## 2. 広告の目的

広告収入をサービス運営費の一部に充てる。

広告は言の葉を置く体験を阻害しない範囲で表示する。

## 3. 広告内容

ユーザーが不快に感じる可能性の高い広告や、サービスの世界観を著しく損なう広告を可能な限り表示しない方針とする。

広告ネットワークを選定する際は、カテゴリ・コンテンツフィルタリング等の機能を確認し、成人向け・ギャンブル等の不適切な広告を制御できる構成を優先する。

具体的な広告ネットワークおよびフィルタリング設定は実装段階で決定する。

## 4. 実装上の方針

広告領域は画面レイアウト上あらかじめ確保し、広告の表示・非表示によって地図や主要操作ボタンの配置が大きく変動しないようにする。
